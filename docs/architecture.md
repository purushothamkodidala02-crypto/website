# Varadhi Architecture

Frontend:
- Next.js

Backend:
- Next.js Server

Database:
- Supabase PostgreSQL

Authentication:
- Supabase Auth

Hosting:
- Cloudflare Workers (via OpenNext, Primary Production) - See docs/cloudflare-failover.md
- Vercel (Backup / Dev)

Version Control:
- GitHub

Project Goal:
A scalable TGPSC mock test platform with an admin dashboard for managing exams, groups, subjects, mock tests, questions, and student results.
